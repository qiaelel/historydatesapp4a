# historydatesapp4a
Проект содержащий даты по истории теперь на Android!
v.1.1

# Основная цель приложения
Основной целью приложения является предоставления дополнительных функций и удобств для пользователя при использовании проекта <a href="https://github.com/qiaelel/historydatesapp">historydatesapp</a>.
На данный момент основная доп. функция приложения это оффлайн доступ, но также планируются и другие интересные функции.

# Требования
Android 7.0+
