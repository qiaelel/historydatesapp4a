# Основная цель приложения
Основной целью приложения является предоставления дополнительных функций и удобств для пользователя при использовании проекта <a href="https://github.com/qiaelel/historydatesapp">historydatesapp</a>. <br>
На данный момент основная доп. функция приложения это оффлайн доступ, но также планируются и другие интересные функции.

# Установка
Вы можете собрать и установить приложение с нуля при помощи Android Studio ,используя файлы репозитория, или скачать готовый .apk файл в releases или с сайта проекта (https://historydatesapp.qiaelel.ru/aplication.html) <br>
Также мы есть в <a href="https://www.rustore.ru/catalog/app/ru.qiaelel.historydatesapp">RuStore</a>.

# Требования
Android 7.0+
